# Evidencia de Vidrala y Viscofan para Munger V2

Repositorio auxiliar para Mistral Code. Sus resultados son propuestas de evidencia pendientes de revisión; no modifican el producto ni acreditan aptitud para invertir.

El encargo y las herramientas se incorporan en `docs/mistral_fuentes_vm/` desde la preparación fijada en el commit `2a6242c88e36b84881f40730aad5125c52c5c977` de `jluisplagos/munger-v2`.

Trabajar en ramas propias; no subir PDF, XLSX, ZIP ni credenciales. No hay integración automática con el repositorio del producto.
